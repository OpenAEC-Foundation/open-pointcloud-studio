Open Pointcloud Studio - first start on macOS

Drag "Open Pointcloud Studio" onto the Applications folder.

This application is not signed with a paid developer certificate and has
not been checked by the system vendor's notarisation service, so macOS
refuses to start it the first time. That is expected, and it has to be
allowed once:

  macOS 15 and later
    1. Start the application and close the message that appears.
    2. Open System Settings > Privacy & Security and scroll down to Security.
    3. Choose "Open Anyway" beside the name of the application and confirm.

  macOS 11 to 14
    1. Control-click (or right-click) the application and choose Open.
    2. Choose Open in the message that appears.

  Either version, from Terminal
    xattr -dr com.apple.quarantine "/Applications/Open Pointcloud Studio.app"

To be sure the download is the published one, compare its SHA-256 checksum
with the .sha256 file beside it on the release page.


Eerste start op macOS

Sleep "Open Pointcloud Studio" naar de map Applications (Apps).

Deze applicatie is niet ondertekend met een betaald ontwikkelaarscertificaat
en niet gecontroleerd door de notarisatiedienst van de systeemleverancier.
macOS weigert haar daarom de eerste keer te starten. Dat is te verwachten en
moet één keer worden toegestaan:

  macOS 15 en nieuwer
    1. Start de applicatie en sluit de melding die verschijnt.
    2. Open Systeeminstellingen > Privacy en beveiliging en scrol naar
       Beveiliging.
    3. Kies "Open toch" naast de naam van de applicatie en bevestig.

  macOS 11 tot en met 14
    1. Control-klik (of rechtsklik) op de applicatie en kies Open.
    2. Kies Open in de melding die verschijnt.

  Beide versies, vanuit Terminal
    xattr -dr com.apple.quarantine "/Applications/Open Pointcloud Studio.app"

Wil je zeker weten dat de download de gepubliceerde is, vergelijk dan de
SHA-256-controlesom met het .sha256-bestand ernaast op de releasepagina.

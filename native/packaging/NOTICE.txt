Open Pointcloud Studio

The desktop application is licensed GPL-3.0-only (LICENSE-GPL-3.0.txt).
It contains ribbon and properties-panel code and icons adapted from a
GPL-3.0 project that is credited in the source headers and in
native/README.md of the source repository. The point-cloud core is
licensed LGPL-3.0-or-later (LICENSE-LGPL-3.0.md).

The embedded fonts Inter and Space Grotesk are licensed under the SIL
Open Font License (the *-OFL.txt files).

The application links Rust crates, each one unmodified and under its own
licence. Writing a drawing as DXF or DWG uses the crate acadrust, version
0.5.5, which is covered by the Mozilla Public License, version 2.0
(https://mozilla.org/MPL/2.0/). Its source code is available from crates.io
under that name and version. native/NOTICE in the source repository lists
it with the crates it brings along.

Every package also carries Open CAD Studio, the open-source CAD
application, as the program that shows exported drawings: OpenCADStudio
(OpenCADStudio.exe on Windows) beside the application, or in
/usr/lib/open-pointcloud-studio in the .deb and the AppImage. It is
licensed GPL-3.0 (OpenCADStudio-LICENSE.txt); OpenCADStudio-NOTICE.txt
names its source and the commit it was built from.

A package for a Debian-based system refers to the licence texts that the
system keeps in /usr/share/common-licenses instead of carrying the
LICENSE files.

The AppImage package starts with the AppImage type 2 runtime, release
20251108 of https://github.com/AppImage/type2-runtime, which is licensed
under the MIT licence; its text and the libraries it links are listed in
AppImage-runtime-LICENSE.txt inside that package. No other package
contains it.

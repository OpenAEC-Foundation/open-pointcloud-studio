# Bundled native UI fonts

- `Inter.ttf` is from [Google Fonts' Inter directory](https://github.com/google/fonts/tree/main/ofl/inter). Its license is `Inter-OFL.txt` (SIL Open Font License 1.1).
- `SpaceGrotesk.ttf` is from [Google Fonts' Space Grotesk directory](https://github.com/google/fonts/tree/main/ofl/spacegrotesk). Its license is `SpaceGrotesk-OFL.txt` (SIL Open Font License 1.1).

These font files are embedded by the Rust desktop binary. No browser or web font loader is used.

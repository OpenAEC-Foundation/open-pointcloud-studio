# Classic desktop tool

This is the original Tauri/React Open Pointcloud Studio v0.3.0, kept separate from the native Rust rebuild in `native/`. Run `./scripts/classic.sh fetch` once, then `./scripts/classic.sh run` to start the old desktop app locally. Run `./scripts/install-classic-desktop.sh` to add a separate “Open Pointcloud Studio Classic” application-menu entry. The copy used for visual comparison is `classic/dist/extracted/usr/bin/open-pointcloud-studio` from the [official v0.3.0 Debian release](https://github.com/OpenAEC-Foundation/open-pointcloud-studio/releases/tag/v0.3.0). The downloaded package and extracted program live under ignored `classic/dist/`; they are not checked into Git.

The original TypeScript frontend and Tauri backend source live in this directory. From the repository root, `./scripts/classic.sh frontend` builds the old frontend into `classic/dist/`. `./scripts/classic.sh dev` and `./scripts/classic.sh build` compile the complete old Tauri app from source with the distinct product name and bundle ID in `classic/src-tauri/tauri.classic.conf.json`. Install the dependencies first with `cd classic && pnpm install`. The desktop source build requires the GTK 3 and WebKit2GTK 4.1 development packages on Linux. They are absent on the current workstation, so the separate locally runnable desktop tool is the official release binary while the frontend has been built from source.

The native replacement in `native/` is all Rust. Classic intentionally retains the old web frontend as an independent reference and usable old application.
